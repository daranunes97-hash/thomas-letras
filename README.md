# Mundo das Letras do Thomas

Jogo de alfabetização para o Thomas (7 anos), num mundo de blocos com um cachorrinho de blocos que o Thomas batiza (toque nele na tela inicial).

- **Jogos:** Letras ⛏️, Sílabas 🔨, Palavras 🐸, Ler 🎤 (ele lê em voz alta e o celular escuta) e Minha casa 🏠 (os acertos viram blocos de construção).
- **App:** tudo está no `index.html`. O `sw.js` faz funcionar sem internet, e o `manifest.webmanifest` com os ícones permitem instalar no celular.
- **Dados:** ficam só no aparelho (localStorage `thomas-letras-v1`).
- **Área dos pais:** segure a ⚙️ por 2 segundos.
